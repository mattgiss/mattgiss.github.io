Brighton Parks and Trails GPS Map

BRIGHTON-2026-10 · Delivered
Brighton, CO, Adams County, CO · Delivered 11 October 2026

Overview

Built for the GPS assignment in the University of Denver GIS and UAS certificate. Eleven public parks and trails around Brighton are recorded as points with a name, category (city park, neighborhood park, regional park, state park, or trail), description, find-it hint, and difficulty rating. The points were exported from ArcGIS Pro with Features To GPX so they load into phone and handheld GPS apps, and the same data is published as a web map symbolized by category with name labels and a trimmed popup.

Processing

SoftwareArcGIS Pro, ArcGIS Online

Coordinate Reference Systems

Horizontal
WGS 84 (GPX); Web Mercator (web map)

Methods

  • Point features for eleven parks and trails with category, description, hint, and difficulty attributes
  • Features To GPX export in ArcGIS Pro for use in GPS apps
  • Hosted feature layer in ArcGIS Online, shared publicly as a read-only view layer
  • Web map symbolized by category with name labels and a trimmed popup

Deliverables

  • GPX file of eleven parks and trails
  • Public web map

Key Technical Challenge

Getting clean GPX waypoints out of ArcGIS Pro, then publishing the same data online without exposing the editable source layer.
